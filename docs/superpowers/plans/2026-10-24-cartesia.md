# Cartesia Outbound Calls Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Cartesia stub with real outbound phone calls through Cartesia Managed Agents: one managed agent whose instructions are filled from our `CallScript` via dynamic variables, calls placed over REST, and the transcript fetched by polling when the call ends and handed to `onCallEnded`.

**Architecture:** No Python Line deployment. A one-time setup script provisions a Cartesia US number and creates (or updates) one managed agent named `mela-caller`, printing the two ids for `.env.local`. At runtime `cartesiaCalls` posts to `/agents/calls` with `dynamic_variables` carrying the script and our call id, then polls `GET /agents/calls/{id}` every 5 s until `completed`/`failed`, flattens `transcript[]` to text, and calls `onCallEnded(callId, transcript)`. The existing `/api/webhooks/call-ended` route stays as a manual fallback.

**Tech Stack:** as the main plan. Global `fetch` with `AbortSignal.timeout`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-24-agent-demo-flow-design.md` (Channels section, "Open for step 9 only").

- Cartesia API facts (verified against docs.cartesia.ai and a live `GET` with the user's key):
  - Base `https://api.cartesia.ai`. Headers on every call: `X-API-Key: <key>`, `Authorization: Bearer <key>`, `Cartesia-Version: 2026-08-14`, `Content-Type: application/json`.
  - `POST /agents/phone-numbers/provision` `{ "label": string }` → a Cartesia US number (free, 1 slot on the free plan). `GET /agents/phone-numbers` → `{ data: [...] }` or an array; each item has `id` (`ap_...`).
  - `POST /v1/agents` `{ name, description?, config: { instructions, initial_message, model: { id }, language: { primary: "en" }, audio: { output: { voice_id } }, system_tools: { end_call: { description, pre_tool_speech: "auto" }, voicemail_detection: { description, pre_tool_speech: "auto", message } }, turn: { inactivity_end_call_secs: 120, inactivity_check_in_secs: 8 }, dynamic_variable_placeholders } }` → `201 { id: "agent_...", ... }`. `PATCH /v1/agents/{id}` with the same `config` updates it (new version; new calls use the latest version). `GET /v1/agents` → `{ data: [{ id, name }] }`. Models: `GET /v1/agents/models`; use `claude-sonnet-5`. Voice id: reuse the account's existing agent voice `db6b0ed5-d5d3-463d-ae85-518a07d3c2b4` unless `CARTESIA_VOICE_ID` is set.
  - `POST /agents/calls` `{ from_number_id, agent_id, ringing_timeout_seconds: 45, outbound_calls: [{ to_number (E.164), dynamic_variables: { ... } }] }` → `200 { calls: [{ number, agent_call_id?, error? }] }`.
  - `GET /agents/calls/{agent_call_id}` → `{ id, status: "created"|"started"|"completed"|"failed", start_time, end_time, transcript: [{ role: "user"|"assistant"|"system", text, start_timestamp, end_timestamp }] | null, summary, end_reason, error_message }`.
- Dynamic variables are `{{name}}` placeholders in `instructions`/`initial_message`, filled per call from `outbound_calls[].dynamic_variables`. Names: letters, digits, underscores.
- Phone numbers come from the store/env only. Scripts come from `CallScript` only. The agent's instructions must say it is an AI assistant calling for a client, that the call is recorded, that it asks only the listed questions, and that it must never agree to `{{must_not_agree_to}}`; end the call with `{{closing}}` then the `end_call` tool.
- Never place a call in tests. All network goes through an injected `fetchImpl`.
- Env: `CARTESIA_API_KEY` (set), `CARTESIA_AGENT_ID`, `CARTESIA_PHONE_NUMBER_ID` (both written by the setup script into `.env.local` only if the user says yes; otherwise printed), optional `CARTESIA_VOICE_ID`.

## Review Focus

- A call that ends with `dial_no_answer`, `dial_busy`, `dial_failed`, `dial_timeout` or `voicemail_detected` → `onCallEnded(callId, "No answer.")` so the orchestrator's Quote agent yields unknowns instead of stalling. Pinned in Task 1.
- Polling gives up after 20 minutes and reports `onCallEnded(callId, "Call did not complete.")` once; a transient 5xx from Get Call does not stop polling. Pinned in Task 1.
- `POST /agents/calls` returning `calls[0].error` → `placeCall` throws with that error; the orchestrator's `call_vendor` refusal path already handles a thrown channel error. Pinned in Task 1.
- Dynamic variable values are strings; question lists are joined with `" | "` and the agent is told that separator. Pinned in Task 1.

```ts
// cartesia.ts
export const AGENT_NAME = "mela-caller";
export const AGENT_INSTRUCTIONS: string;   // uses {{call_kind}}, {{questions}}, {{closing}}, {{must_not_agree_to}}; see constraints
export type CartesiaClient = {
  listPhoneNumbers(): Promise<{ id: string; number?: string; label?: string }[]>;
  provisionNumber(label: string): Promise<{ id: string; number?: string }>;
  listAgents(): Promise<{ id: string; name: string }[]>;
  createAgent(config: object): Promise<{ id: string }>;
  updateAgent(id: string, config: object): Promise<void>;
  placeCall(args: { fromNumberId: string; agentId: string; toNumber: string; variables: Record<string, string> }): Promise<{ agentCallId: string }>;  // throws Error(calls[0].error) when present
  getCall(agentCallId: string): Promise<{ status: string; endReason: string | null; transcript: { role: string; text: string | null }[] | null }>;
};
export function cartesiaClient(env: NodeJS.ProcessEnv = process.env, fetchImpl: typeof fetch = fetch): CartesiaClient;  // throws "Cartesia not configured" without CARTESIA_API_KEY; 15 s timeout per request; non-2xx → Error(`cartesia ${status} ${body.slice(0,200)}`)
export function agentConfig(voiceId: string): object;      // the managed-agent config from the constraints, model claude-sonnet-5
export function scriptVariables(kind: CallKind, script: CallScript, melaCallId: string): Record<string, string>;
// { call_kind: kind, opening: script.opening, questions: script.questions.join(" | "), closing: script.closing, must_not_agree_to: script.mustNotAgreeTo.join(", "), mela_call_id: melaCallId }
export function transcriptText(items: { role: string; text: string | null }[] | null): string;  // "Agent: …\nVendor: …" lines (role assistant → "Agent", user → "Callee"), empty → ""
export function finalTranscript(call: { status: string; endReason: string | null; transcript: ... }): string | null;
// null while status is created/started; "No answer." for end reasons dial_no_answer|dial_busy|dial_failed|dial_timeout|voicemail_detected; otherwise transcriptText (or "Call did not complete." when failed with an empty transcript)
export function pollUntilEnded(client: CartesiaClient, agentCallId: string, onDone: (t: string) => Promise<void>, opts?: { intervalMs?: number; maxMs?: number; sleep?: (ms: number) => Promise<void> }): Promise<void>;
// every 5 s (default) up to 20 min; a thrown getCall is logged and retried; calls onDone exactly once
export function cartesiaCalls(onCallEnded: OnCallEnded, store: Store, client?: CartesiaClient): Pick<Channel, "callHost" | "callVendor">;
// reads CARTESIA_AGENT_ID / CARTESIA_PHONE_NUMBER_ID (throw "Cartesia not configured: run npm run cartesia:setup" if missing); placeCall; start pollUntilEnded detached (void …catch(console.error)) with onDone = (t) => onCallEnded(callId, t); return { callId, providerCallId: agentCallId }
// scripts/cartesia-setup.ts: loads ./env; lists numbers (provision "Mela" if none, confirm via CLI arg --provision, else print instructions); finds agent named mela-caller (create or update with agentConfig(voiceId)); prints `CARTESIA_AGENT_ID=…` and `CARTESIA_PHONE_NUMBER_ID=…`; with --write appends/updates those two lines in .env.local. Never prints the API key.
```
